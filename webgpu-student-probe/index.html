Can a recurrent neural network actually run on this device's GPU?

This is a real ONNX neural inference test, not a demo of RTNVE's artistic quality. The tiny network's weights are random and untrained. It will never show convincing hallucinations. It only measures whether PyTorch-exported, stateful neural computation runs through WebGPU inside this browser, including on a phone.

The model runs entirely on your device. This page does not upload it. Use training/export_webgpu_student_probe.py to create one.

Performance and compatibility

No results yet.

Output is measured as neural inference iterations per second, not AnimateDiff-quality generated FPS. The output tensor is fed back into the next inference while remaining GPU-resident when supported. Each iteration does convolutional neural-network work using ONNX Runtime WebGPU, but no learned visual dynamics yet.

Don't compare this tiny network's FPS directly with a finished video model: it has orders of magnitude fewer learned parameters and does not decode full video frames. It's only the first transport / compatibility test.
